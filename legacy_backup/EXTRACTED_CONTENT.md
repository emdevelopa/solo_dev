- **Tags**: `Next.js`, `TypeScript`, `Python`, `Django`, `MySQL`, `Tailwind CSS`
- **Key Highlights**: Interactive Dashboard, Real-time Metrics, Granular Transaction Logs

### Project 3: MOVIEBOX
- **Category**: Web App
- **Live URL**: [https://movie-box-nine-gamma.vercel.app/](https://movie-box-nine-gamma.vercel.app/)

- **Tags**: `React.js`, `Tailwind CSS`, `TMDB API`, `Framer Motion`, `SPA`
- **Key Highlights**: Debounced Search, TMDB API Integration, Dynamic Recommendations
